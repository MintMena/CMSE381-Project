This project looks at what affects students' exam scores from 6,607 students and 19 factors like attendance, study hours, sleep and family background.
We predicted exam scores with OLS, Ridge, Lasso and PCR. Then sorted students into Low/Medium/High groups with logistic regression.

---

Dataset used: StudentPerformanceFactors.csv

Results: 
- R-squared for PCR ~ 0.73 hence typical error is about 2 points
- Logistic regression returns 96.6% accuracy

Conclusion:
- Attendance and hours studied were the strongest predictors
- PCA showed the main pattern in data is student engagement
